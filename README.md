# Tokyo Ghoul: Rebirth

A complete and complex incremental RPG survival game themed around Tokyo Ghoul.

## Features

- **Survival & Exploration**: Procedural sector generation within Tokyo's districts.
- **Base Building**: Construct and manage hideouts to survive and produce resources.
- **Paths**: Choose between becoming a Ghoul or a CCG Investigator.
- **Combat**: Turn-based battle system with RC type advantages and Kagune/Quinque mechanics.
- **Incremental Progress**: Resource management, research (Tech Tree), and rank progression.

## Tech Stack

- **React**: UI Library
- **Zustand**: State management (with persistence)
- **Tailwind CSS**: Styling
- **Lucide React**: Icons
- **Vite**: Build tool

## Getting Started

1. Install dependencies: `npm install`
2. Start development server: `npm run dev`
3. Build for production: `npm run build`
